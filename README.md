# Meconopsisdtfhg Website

Professional responsive jewelry website for **Meconopsisdtfhg**.

## Included
- Elegant jewelry homepage
- Rings, necklaces, bracelets, and earrings
- Product category filters
- Sample pricing
- Interactive bag counter
- Brand story and About section
- Newsletter form
- Responsive mobile navigation
- GitHub Pages ready

## Files
- `index.html`
- `styles.css`
- `script.js`

## Publish with GitHub Pages
Upload all files to the root of the `meconopsisdtfhg` repository.

Then go to:

**Settings → Pages → Deploy from a branch → main / root → Save**

Product names and prices are sample content and can be replaced with your real inventory. Photography is loaded from Unsplash.
